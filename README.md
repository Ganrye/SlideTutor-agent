# SlideTutor Agent

SlideTutor Agent is an interactive GUI teaching agent for self-learning. It transforms static PPT/PDF slides into a structured learning flow with highlights, masks, questions, review jumps, and feedback.

## Current Demo Goal

Given a fixed lesson JSON, the web app executes GUI actions:
- highlight
- mask
- jump
- question_popup
- feedback

## Quick Start

cd apps/web
npm install
npm run dev
